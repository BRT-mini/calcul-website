# Калькулятор работ автосервиса

Статическое мини-приложение для оператора коллцентра:

```text
Марка -> модель -> год -> одна или несколько работ -> строки, сумма и время
```

## Как открыть

```bash
python3 -m http.server 8080 --directory workspace/autoservice-calculator
```

Затем открыть:

```text
http://127.0.0.1:8080
```

## Импорт Excel с нормо-часами

Полученный файл `новая таблица часов.xls` фактически является современным Excel-файлом внутри. В нем 4 колонки:

```text
Модель
Год выпуска
Авторабота
Количество нч
```

В файле нет готовой цены в рублях. Цена считается так:

```text
стоимость = количество нормо-часов * ставка нормо-часа
```

Команда импорта:

```bash
python3 workspace/autoservice-calculator/scripts/convert_hours_xlsx.py \
  "/Users/sergejpugacev/Downloads/новая таблица часов.xls" \
  workspace/autoservice-calculator/data/services.json \
  --hour-rate 3400 \
  --updated-at 2026-05-18
```

Текущая ставка нормо-часа: `3400 ₽`.

## Как обрабатываются особенности файла

- `year = 1` считается общей работой для модели и разворачивается на все конкретные годы этой модели из файла.
- Если для одной машины, года и работы есть несколько нормо-часов, берется максимальное значение, а статус становится `check`.
- Строки без нормо-часов или с отрицательными нормо-часами пропускаются.
- Марка и модель берутся из колонки `Модель`, например `LAND ROVER DISCOVERY IV (2009-)` -> `LAND ROVER` и `DISCOVERY IV (2009-)`.

## Несколько работ

Оператор может добавить в смету две, три или больше работ. Итоговая стоимость и время считаются по найденным работам, а отсутствующие позиции остаются в смете с предупреждением.
